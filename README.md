# Student Mental Health Impact of Social Media Usage

## Project Overview
This project explores the relationship between social media usage and students' mental health. It focuses on analyzing how daily social media habits, screen time, sleep patterns, physical activity, and other factors may be associated with students' mental health scores.

The project uses Machine Learning regression models to predict students' mental health scores based on the available dataset.

## Objectives
- Analyze the impact of social media usage on students' mental health.
- Explore relationships between screen time, sleep, physical activity, and stress levels.
- Perform data preprocessing and feature engineering.
- Build and evaluate Machine Learning regression models.
- Compare model performance and select the best-performing model.

## Machine Learning Models

Two regression models were implemented:

1. **Linear Regression**
2. **Random Forest Regressor**

Both models were trained and evaluated using different performance metrics.

## Model Evaluation Metrics
- R² Score
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)

After comparing the evaluation metrics, the **Random Forest Regressor** was selected as the final model and saved using Joblib for future use.
